# 🎯 Jogo da Adivinhação em Python

Um jogo de adivinhação simples e interativo desenvolvido em Python, onde o objetivo é descobrir um número secreto sorteado entre 1 e 99 com o menor número de tentativas possível.

Este projeto foi criado com foco em lógica de programação e boas práticas para iniciantes, utilizando exclusivamente a biblioteca padrão do Python.

# 🎮 Como Jogar
O programa irá sortear um número aleatório entre 1 e 99.

Digite seu palpite no terminal e pressione Enter.

O jogo dará dicas se o número secreto é maior ou menor que o seu palpite.

Continue tentando até acertar! Ao final, seu total de tentativas será exibido.

# 🛠️ Tecnologias Utilizadas

Python 3 (Linguagem de programação)

Random (Módulo nativo para geração de números aleatórios)


# 💡 Funcionalidades
- Sorteio aleatório de números.
- Tratamento de erros para entradas inválidas (letras ou caracteres especiais).
- Validação de intervalo (apenas números entre 1 e 99).
- Contador de tentativas.
